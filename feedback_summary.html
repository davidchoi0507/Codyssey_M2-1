1. 원일님 피드백 반영 사항 4건 완료
OAuth 소셜 로그인 토큰 유실 버그 수정 반영 완료

페이지 로드 시 '뒤로 가기' 히스토리 교체가 URL 해시(#session=토큰)를 지워버려 로그인이 401로 풀리던 문제를 수정했습니다. 해시 추출을 최우선 실행하고 주소 교체 시에도 해시를 온전히 보존합니다.

'이 브라우저에서 공개한 곡' 목록 동기화 및 중복 정리 반영 완료

서버에서 삭제된 404 곡을 로컬 목록에서 자동 제외하고, 로그인 후 '내 곡'으로 가져온 곡이 중복 표시되지 않도록 필터링했습니다. 개별 삭제(✕) 버튼도 추가했습니다.

1단계 곡 정보 수정 시 서버 자동 동기화 반영 반영 완료

백엔드에서 곡 정보 수정 시 커뮤니티 공개곡까지 일괄 갱신하도록 개선됨에 따라, 프론트엔드의 중복 호출(publishFromJob)을 정리했습니다.

서비스 소개 독립 '홈' 탭 신설 및 스튜디오 사용성 복원 반영 완료

작업 화면 상단의 큰 배너를 분리하여, 첫 화면에 시원시원한 독립 '홈' 페이지를 신설했습니다. 발매 준비(스튜디오) 화면은 불필요한 설명 없이 쾌적한 본래 작업대로 100% 원상 복원되었습니다.

2. 은희님 피드백 반영 사항 4건 완료

모바일 기기에서 상단 '발매로' 로고의 그라디언트 텍스트 윗부분이 바운딩 박스에 잘리던 현상을 수직 여백 및 라인하이트 확보를 통해 해결했습니다.

커뮤니티 스크롤 시 하단 오디오 플레이어 상시 고정 반영 완료

모바일 커뮤니티 리스트 뷰 긴 제목 가독성 개선 반영 완료
