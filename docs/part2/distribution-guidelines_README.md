# 📋 음원 유통사 및 스트리밍 플랫폼 규격 가이드라인

> 이 문서는 **인디 앨범 스튜디오(Indie Album Studio)**의 "음원 유통·발매 패키징 서비스" 개발을 위해,  
> 국내외 주요 유통사(Distributor) 및 스트리밍 플랫폼(DSP)의 규격, 요구사항, 반려 규정을 체계적으로 수집·정리하는 공간입니다.

---

## 📁 디렉토리 권장 구조

이 브랜치에는 문서(.md)뿐만 아니라 유통사에서 배포하는 공식 가이드 PDF나 신청서 엑셀 양식(.xlsx)도 함께 올려주시면 개발 및 AI 프롬프트 작성 시 즉시 분석하여 반영할 수 있습니다.

```
docs/guidelines/
├── README.md (본 문서)
├── distributors/               # 유통사별 상세 규격 및 신청서 양식
│   ├── poclanos.md             # 포크라노스 (Poclanos)
│   ├── quarter_music.md        # 쿼터뮤직 (Quarter Music)
│   ├── distrokid.md            # 디스트로키드 (DistroKid)
│   └── templates/              # 유통사 공식 엑셀/신청서 템플릿 (.xlsx, .pdf)
├── platforms/                  # 스트리밍 플랫폼별 세부 가이드
│   ├── spotify.md              # Spotify (Canvas 영상 규격, Loudness 등)
│   ├── apple_music.md          # Apple Music (모션 아트워크, 고해상도 오디오)
│   └── melon.md                # 멜론 (한글/영문 메타데이터, 가사 표기법)
└── legal_and_censorship.md     # 방송 심의(지상파 3사), 저작권 신탁, 행정 절차
```

## 📌 주요 정리 대상 체크리스트

### 1. 오디오 규격 (Audio Specification)
* [ ] 허용 확장자: WAV (24-bit / 48kHz, 16-bit / 44.1kHz 등)
* [ ] 헤드/테일 무음 기준 (앞/뒤 몇 초 이내 허용인지)
* [ ] True Peak 및 LUFS 권장 기준 (플랫폼별 왜곡 방지 레벨)

### 2. 커버 아트워크 규격 (Cover Art Specification)
* [ ] 이미지 해상도: 3000 × 3000 px (1:1 비율)
* [ ] 색상 공간: RGB (CMYK 반려 여부)
* [ ] 포맷 및 최대 파일 용량: JPG / PNG (용량 제한)
* [ ] **주요 반려(Rejection) 사유 목록**:
  * 스트리밍사 로고, 바코드, 가격, SNS 아이디(@) 포함 여부
  * 앨범 커버 상 텍스트와 메타데이터 철자 불일치
  * 해상도 저하(픽셀 깨짐, 업스케일링 흔적)

### 3. 메타데이터 & 표기법 규칙 (Metadata & Text Rules)
* [ ] 아티스트명 / 앨범명 영문·한글 병기 규칙
* [ ] 피처링 표기 규칙 (`feat.` vs `Featuring` vs 괄호 사용 유무)
* [ ] 트랙 크레딧 필수 항목 (작사, 작곡, 편곡, 믹싱, 마스터링, 세션 연주자)
* [ ] 가사 제출 형식 (일반 텍스트, LRC 타임스탬프 싱크 가사, 심의용 가사 표기)

### 4. 행정 및 심의 절차 (Censorship & Legal)
* [ ] 방송 3사(KBS, MBC, SBS) 방송 심의 제출 서식 및 절차
* [ ] 유통사 접수 리드타임 (발매 희망일 최소 며칠 전 제출해야 하는지)
* [ ] ISRC / UPC 코드 발급 방식 (유통사 무료 발급 여부)
