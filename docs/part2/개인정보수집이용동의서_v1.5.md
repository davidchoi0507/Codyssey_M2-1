# [발매로] 서비스 이용 및 개인정보 수집·이용 동의서 (v1.5)

> **버전** v1.5 · **시행일** 2026-10-13 · **서비스 종료 예정일** 2026-10-31 (종료 시 전체 삭제)
> **문의/개인정보 보호책임자** admin@201.n-e.kr · 10일 이내 회신

본 동의서는 코디세이 프로젝트팀 중 [발매로]팀(이하 '회사')이 제공하는 **AI 기반 음원 발매 패키징 및 홍보 콘텐츠 제작 서비스**를 위한 것입니다.

- **한 줄 정의:** 처음 만든 내 노래를, 발매하는 방법부터 사람들 반응까지 한 곳에서.
- **본 서비스는 유통 대행을 하지 않으며**, 반려 위험을 줄이는 검사·정리 도구입니다.
- **만 14세 이상**만 이용할 수 있습니다.

> ⚠️ 유통은 회사가 직접 하지 않으며, 이용자가 선택한 유통사에 제출할 자료를 준비·정리(Export)하는 것까지가 서비스 범위입니다.

---

## 제1조 (개인정보 수집 및 이용 동의 - 필수)

1. **수집 목적:** 서비스 이용·식별, AI A&R 노트·커버·숏폼·소개글·피칭 생성, 음원·커버·표기·권리 규격 검사 및 유통사별 제출 자료 Export 생성, 이용 기록 분석·안정성 확보, 문의 응대·분쟁 조정, 부정 이용·도배 방지
2. **수집 항목:**
   - 곡 정보: 곡 제목, 아티스트명, 음원, 가사, 곡 소개, 장르·무드
   - 구조화 크레딧: 작사·작곡·편곡, 피처링·세션, 원곡자 정보(커버·샘플 시), 레이블명 — *크레딧에 포함된 타인(참여자) 이름은 참여자 동의를 받은 경우에만 입력*
   - 유통사 제출 준비 정보: 발매일, 언어, 가사 유무, 성인물 여부 등
   - 접속 IP (도배 방지·부정 이용 방지용, 7일 보관), 업로드 사진, (로그인 시) 제5조 로그인 정보
3. **유통사 제출 자료 생성·Export 안내 (구 제7조 통합):**
   - 회사는 이용자 입력 정보를 유통사별 규격에 맞춰 정리한 제출 준비표 및 파일 묶음(ZIP Export)을 생성합니다.
   - Export를 유통사에 전달하는 주체는 **이용자 본인**입니다. 회사는 직접 전송하지 않습니다.
   - 타인 정보 포함: 크레딧의 피처링·연주·작사·작곡 참여자 이름 포함 가능. 이용자는 참여자 동의를 사전 확보해야 하며 책임은 이용자에게 있음
   - 보유·이용 기간: 생성 후 7일 뒤 자동 삭제. 로그인 이용자가 '내 작업' 저장 시 직접 삭제·탈퇴 요청 시까지 보관, 서비스 종료일에 모두 삭제
   - 규격 검사 결과의 성격: 참고용이며 유통사 통과 미보장(제3조 4항 동일)
4. **보유·이용 기간:**

| 구분 | 기간 |
|---|---|
| 원칙 | 업로드 후 7일 뒤 자동 삭제 |
| 커뮤니티 공개곡 (제6조) | 직접 내릴 때까지 / 종료일 삭제 |
| 제출 자료 Export (구 제7조) | 생성 후 7일 / 저장 시 탈퇴·종료일 삭제 |
| 권리 자가진단 (구 제8조, 제3조에 통합) | 해당 곡 보관 기간 / 종료일 삭제 |
| 로그인 정보 (제5조) | 탈퇴 시까지 / 종료일 일괄 삭제 |
| 반응 IP 및 신고 IP (제7조) | 작성 후 7일 뒤 자동 삭제 |

5. **동의 거부 권리:** 거부 가능하나 필수 항목 거부 시 AI 생성·발매 패키징 이용 제한
6. **개인정보 보호책임자:** 발매로팀 보호책임자 / admin@201.n-e.kr
7. **이용자의 권리:** 열람·정정·삭제·처리정지·동의철회 요청 가능 — admin@201.n-e.kr 로 요청, 요청 후 **10일 이내** 처리 결과 안내
8. **이용 연령:** 만 14세 이상만 이용 가능

## 제2조 (외부 AI API 제3자 제공 및 위탁 처리 동의 - 필수)

1. **제공받는 자:** OpenAI(미국), Google Gemini(미국) — 음원 분석: Gemini / 글·이미지: 코디세이 API 경유 OpenAI
2. **제공 항목:** 음원 분석 데이터, 입력 텍스트(가사·장르·무드·크레딧 등), 업로드 사진
3. **제공 목적:** AI 곡 해석(A&R 노트), 커버·숏폼·소개글 생성, 규격·커버 검사 보조
4. **학습 활용:** OpenAI — 학습 미사용 / Gemini(무료) — 학습·개선 저장·사용 가능 / 코디세이 API — 학습 미사용
5. **보유·이용 기간:** OpenAI 최대 30일 후 파기 / Gemini 제공사 정책
6. **국외 이전(법 제28조의8):** 이전받는 자·국가(OpenAI·Gemini/미국), 항목(텍스트·음원·사진), 목적(AI 콘텐츠 생성·분석), 기간(상기 5항)

> 동의하지 않을 경우 AI 콘텐츠 생성·해석 서비스 이용이 제한됩니다.

## 제3조 (저작권 및 결과물 이용 - 필수)

1. **권리 보증:** 음원·텍스트·사진·크레딧 참여자 명의 권리는 사용자에게 있으며, 생성·제출에 필요한 모든 권리(초상권·저작물·피처링/연주자 동의 포함)를 사전 확보해야 함. 무단 침해 책임은 사용자
2. **결과물 귀속:** AI 생성물 사용권·소유권은 사용자에게 귀속되나 저작권 미인정 가능
3. **면책:** 회사는 독창성·비침해를 보증하지 않으며 고의·중과실 없는 한 분쟁 책임 미부담
4. **규격·권리 검사의 성격:** 참고 정보이며 반려율 0%·유통사 통과 미보장. 최종 제출·발매 책임은 사용자
5. **권리 자가진단 안내 (구 제8조 통합):**
   - 수집 목적: 커버곡·샘플·AI 활용 여부 등 권리 관계 확인, 권리 표기 보조, 반려 위험 안내
   - 수집 항목: 창작 유형(자작곡/커버/리메이크/샘플), 커버 시 원곡 정보·신탁 이용허락 확보 여부, AI 활용 표기(작곡·편곡·보컬·가사·커버 이미지), 참여자 동의 확보 여부
   - 이용 방식: 권리 위험 안내 및 제1조 제출 자료의 권리 표기 작성에 활용
   - 자가진단의 성격: 이용자 응답 기반 참고 정보이며 회사가 법적 검증·보증하지 않음. 응답 정확성·실제 권리 확보 책임은 이용자
   - 보유·이용 기간: 해당 곡 보관 기간을 따름, 서비스 종료일에 모두 삭제
6. **금지된 사용:** 폭력·선정·혐오·명예훼손 콘텐츠 금지, 적발 시 경고·정지·삭제

## 제4조 (마케팅 및 서비스 개선 - 선택)

1. **목적:** UI/UX·AI 품질·발매 패키징 개선 분석, 최종 발표 자료 활용
2. **항목:** 결과물 썸네일, 업로드 사진 (음원 제외)
3. **기간:** 업로드 후 7일 삭제 (발표 활용 시 발표 종료 후 30일 내 삭제)
4. **거부 권리:** 거부해도 서비스 이용 가능

## 제5조 (소셜 로그인 정보 수집 및 이용 - 선택)

> 로그인 화면에서 별도로 동의받습니다.

1. **수집 목적:** 이용자 식별, 내 작업·커뮤니티 곡·제출 자료 모아보기, 이용 한도 관리, 부정 이용 방지
2. **수집 항목:** 카카오·구글 회원 고유 식별값(ID), 닉네임, 로그인 일시 *(이메일 현재 미수집, 수집 시 목적 명시 필요)*
3. **수집 방법:** 카카오·구글 로그인 동의 시 전달받음. 비밀번호 미수집·미저장
4. **보유·이용 기간:** 탈퇴 요청 시까지, 서비스 종료일(**2026-10-31**)에 전부 삭제
5. **동의 거부 권리:** 미동의 시 관리 링크 방식 이용 가능(모아보기 제외)

> 로그인 없이도 곡마다 발급되는 관리 링크로 모든 발매 패키징 기능을 이용할 수 있습니다. 단, '내 곡 모아보기'는 로그인 시에만 제공됩니다.

---

## 제6조 (커뮤니티 공개에 관한 동의 - 선택)

> 곡을 커뮤니티에 올릴 때마다 별도로 동의받습니다.

1. **공개 범위:** 로그인하지 않은 사람 포함 누구나 듣고 볼 수 있음
2. **공개 항목:** 음원(전곡/하이라이트), 곡 제목·아티스트명·장르·소개, 커버 이미지, 재생 수·반응 통계
3. **반응 공개 설정:** 별점·태그·한마디 전체 공개/나만 보기 선택, 언제든 변경
4. **보유·이용 기간:** 이용자가 내릴 때까지, 서비스 종료일(**2026-10-31**)에 전부 삭제. 하이라이트만 공개 시 전곡 사본 미보관
5. **내리기:** 관리 링크 또는 '내 곡'에서 언제든 내림, 내린 곡·반응 지체 없이 삭제
6. **권리 보증:** 공개 콘텐츠 권리 보유 필수, 무단 커버곡·샘플 금지
7. **복제 위험 안내:** 공개 음원은 녹음·다운로드될 수 있으므로 발매 전 곡은 하이라이트 공개 권장
8. **동의 거부 권리:** 미동의 시 커뮤니티 공개 제외 이용 가능

---

## 제7조 (커뮤니티 이용 규칙)

> 커뮤니티 이용자 모두(게시자·반응 작성자)에게 적용됩니다.

1. **반응 남기기:** 로그인 없이 별점·태그·한마디·닉네임(선택)으로 가능
2. **반응 수집 정보:** 닉네임(선택), 별점·태그·한마디, 작성 시각, 접속 IP (IP는 도배 방지·신고 처리용, 화면 미표시, 작성 후 **7일** 뒤 삭제. 반응 내용은 곡 내림·종료 시 삭제)
3. **금지 행위:** 욕설·비방·혐오, 광고·홍보, 도배, 매크로, 타인 곡 무단 등록 (단, 게시자는 소개에 본인 SNS·음원 링크 가능)
4. **자동 거절:** 금지 행위 글 미등록, 단시간 과다 등록 시 일시 제한
5. **신고와 숨김:** 누구나 신고 가능, 서로 다른 사람 3회 이상 신고 시 자동 숨김 후 운영자 확인(복원/삭제). 무단 등록 확인 시 곡 내림. **신고 시 수집되는 신고자의 접속 IP도 도배 방지·허위 신고 방지 목적으로 7일간 보관 후 삭제**
6. **운영자 조치:** 위반 곡·반응은 사전 안내 없이 숨김·삭제, 반복 위반 시 이용 제한

> **반응 입력칸 안내 문구:** "반응은 곡을 올린 분과 (공개 설정 시) 다른 방문자에게 보입니다. 도배 방지를 위해 접속 IP가 7일 동안 보관되며 화면에는 표시되지 않으며, 욕설·광고·도배는 등록되지 않습니다."

## 발매 패키징 서비스 안내 및 면책

1. **서비스 범위 (유통 대행 아님):**
   - 제출 전 검수 24항목: 음원 포맷, 커버 3000px 규격, 표기·금칙어, 권리 자가진단 등
   - AI A&R 노트, 에디토리얼 피칭문구, 발매 캘린더 제안
   - 유통사별 입력 순서에 맞춘 제출 준비표 및 파일 묶음 ZIP Export
2. **비보장 고지:** **반려율 0%·통과 보장하지 않습니다.** 검수는 유통사별 규격 프로파일 기반 사전 점검으로, 최종 심사는 각 유통사·플랫폼 정책에 따릅니다.
3. **유통사 규격 프로파일:** 규격은 플랫폼이 아니라 유통사마다 다릅니다. 회사는 프로파일을 유지·업데이트하며 변경 시 화면에 안내합니다.
