# 발매로 — 기능 요구 명세서

> 작성: 백엔드(원일) 초안 · 2026-10-19 · 기준: 실서버 `api.201.n-e.kr` (woniri 브랜치)
> 우선순위: **Must** = 제출 범위에서 꼭 동작, **Should** = 동작하지만 범위가 작음, **Could** = 제출 뒤 과제

## 1. 서비스 한 줄

처음 곡을 내는 사람이 **음원 파일 하나**를 올리면, AI가 곡을 먼저 듣고 해석한 **A&R 노트**를 보여 주고, 사람이 그 해석을 확인·수정하면 그 해석 하나로 **커버·숏폼·홍보 글·피칭 메일**을 만들고 **유통사 등록 전 검사**까지 끝낸다. 만든 곡은 커뮤니티 **'들어봐'**에 올려 반응을 받는다.

## 2. 사용자

| 사용자 | 하는 일 |
| --- | --- |
| 곡을 올리는 사람 (인디 뮤지션·학생·취미 창작자) | 곡 업로드 → 노트 확인 → 결과물 받기 → 유통사 검사 → 커뮤니티 공개 |
| 듣는 사람 | 로그인 없이 '들어봐'에서 곡 듣기, 별점·태그·한마디, 신고 |
| 운영자 (팀) | 신고 확인, 사용 기록·설문 요약(/admin) |

## 3. 기능 요구사항 (FR)

### 3.1 곡 업로드·분석

| ID | 요구사항 | 우선 | 구현 |
| --- | --- | --- | --- |
| FR-01 | mp3·wav 업로드 (최대 200MB, 15초~10분). 형식·길이·손상 파일은 AI 분석 전에 거절하고 한국어로 이유를 알린다 | Must | `POST /jobs` |
| FR-02 | 업로드 전 동의 4가지(만 14세 이상·개인정보, 외부 AI 전송, 권리 확약 — 필수 / 발표 활용 — 선택)를 받지 않으면 처리하지 않는다. 동의 문구 버전과 시각을 기록한다 | Must | 동의서 v1.6 |
| FR-03 | 곡을 수치로 측정한다: BPM, 키, 에너지 곡선, 구간, 파형, 15초 하이라이트 후보 3개 | Must | librosa |
| FR-04 | AI가 음원을 직접 듣고 감정 흐름·악기·보컬 질감을 서술하고, 하이라이트 후보 중 하나를 이유와 함께 고른다 | Must | Gemini (오디오 입력) |
| FR-05 | 두 결과를 합쳐 A&R 노트(한 줄 콘셉트, 무드 키워드, 곡의 색 3개, 커버 방향, 추천 하이라이트)를 만든다 | Must | A&R 에이전트 |
| FR-06 | 분석 중 단계별 진행(수치 재기 → 듣기 → 해석 쓰기)과 대기 순번을 보여 준다 | Should | `GET /jobs/{id}` |
| FR-07 | 상용곡·이미 공개된 곡과 같은 녹음이면 업로드 직후 막는다 | Should | Chromaprint 지문 + AcoustID |
| FR-08 | 곡이 없는 사람을 위한 체험 모드: 예시 곡으로 몇 초 만에 노트, 이후 생성은 실제로 하고 공개만 막는다 | Should | `POST /jobs/demo` |

### 3.7 제출 뒤 과제 (Could)

- 관리 링크 비밀번호, 여러 기기 동시 수정 충돌 처리
- 만 14세 미만 법정대리인 동의
- ZIP 안 홍보 글을 화면에서 고친 내용으로 저장
- 스마트링크·이메일 발송, 밴드별 화풍(LoRA)

## 5. AI 활용 명세

| 단계 | AI | 입력 | 출력 | 사람이 개입하는 곳 |
| --- | --- | --- | --- | --- |
| 듣기 | Gemini 3.8 Flash (오디오 입력) | 압축 음원 + librosa 수치 + 하이라이트 후보 | 감정 흐름·악기·보컬·추천 구간 JSON | — |
| A&R 노트 | 코디세이 LLM (gpt-5.4) + LangChain | 수치 + 듣기 결과 | 노트 JSON | **수정·수락** |
| 비주얼 디렉터 | 코디세이 LLM | 확정 노트 | 커버 프롬프트 3개 | 커버 선택·다시 만들기 |
| 커버 이미지 | 코디세이 이미지 (gpt-image-2) | 프롬프트 | 커버 → 3000px | 내 사진으로 바꾸기 |
| 커버 검수 | Gemini Flash Lite (이미지 입력) | 고른 커버 | 유통사 반려 1순위 항목(글자·워터마크·로고·URL·선정성·흐림) 찾기 → 3단계 검사에 반영 | — |
| 카피라이터 | 코디세이 LLM (gpt-5.4-mini) | 확정 노트 | 채널 4종 홍보 글 | 다시 만들기 |
| 피칭·에디토리얼 | 코디세이 LLM | 확정 노트 | 피칭 메일(영·한), Spotify 피칭 | 다시 만들기 |

- **환각 방지**: 시간·BPM·구간은 librosa 측정값을 코드가 붙이고 LLM은 다시 쓰지 않는다. 노트 문장의 시간 표기는 실제 곡 길이와 대조해 검사한다.
- **사람 중심**: 해석을 먼저 보여 주고 사람이 고치거나 수락해야 생성이 시작된다. 생성물은 모두 이 확정 노트 하나를 근거로 해서 톤이 일관된다.
- **쓰지 않은 것**: RAG(유통사 규격은 정확해야 해서 코드 규칙으로 검사), 장기 메모리(계정의 '내 곡'으로 대신).
