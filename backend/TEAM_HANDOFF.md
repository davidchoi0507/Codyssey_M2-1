## 2. 팀장님께 (화면)

### 2-1. 전달

**업로드 조건이 바뀌었습니다**
- 파일: `.mp3`, `.wav` / **200MB 이하** (기존 50MB에서 변경) / **10분 이하**
- 이유: 3분짜리 WAV가 약 66MB라 50MB로는 WAV 대부분이 막힙니다. 서버가 받은 뒤 WAV를 무손실(FLAC)로 줄여 저장합니다.
- 👉 업로드 화면 안내 문구를 "200MB·10분 이하"로 바꿔 주세요.

**A&R 노트 실제 예시 (샘플 곡)**

```
해석: 체감은 68 BPM의 차분한 발라드인데, 실제 136 BPM의 추진력 위에서 2:13 이후 에너지가
      약 2.2배로 뛰며 회상과 이별이 후반 폭발로 넘어갑니다. 2:36~2:40에 가장 높게 치솟았다가
      끝에 힘을 빼며 쓸쓸한 여운을 남기는 곡이에요.
키워드: 회상 · 그리움 · 애틋함 · 격정 · 여운
색: #6F7C8F #C96A4A #1F2430
커버 방향: ① 저녁 골목길을 홀로 걷는 뒷모습, 사진
          ② 붉게 번지는 하늘과 흩어진 계절의 잔상, 일러스트
          ③ 어쿠스틱 기타 실루엣이 일렉트릭 파형처럼 갈라지는 장면, 그래픽
하이라이트: ★0:41~0:56 밴드가 들어오며 보컬 훅이 또렷해요 (추천)
            1:18~1:33 / 2:14~2:29
```

- 노트 JSON 형식은 기획 문서의 API 계약 초안 그대로입니다 (`interpretation`, `evidence`, `mood_keywords` 5개, `colors` 3개, `cover_directions` 3개, `highlight.candidates` 3개 + `recommended_id`, `waveform` 800개 값).
- **파형(`waveform`)은 0~1 사이 숫자 800개**입니다. 하이라이트 미리 듣기는 브라우저가 사용자가 올린 원본 파일을 직접 재생하면 됩니다 (`start`/`end`는 초 단위).
- 화면 문구에 쓰일 글(해석·이유)은 시간을 "2:34"처럼 분:초로, 내부 수치 없이 나오게 맞춰 두었습니다.
- 10/5에 샘플 결과 JSON 파일(3곡)을 드려서, 백엔드를 기다리지 않고 화면 작업을 할 수 있게 하겠습니다.

**진행 화면 시간 참고**
- 수치(BPM·파형)는 업로드 후 약 10초 안에 먼저 나옵니다 → 진행 화면에 먼저 보여줄 수 있습니다.
- 전체 노트까지 약 30~40초. 단, Gemini 서버가 붐비면 재시도로 1분 이상 걸리거나 실패할 수 있어서, **실패 시 "다시 시도" 버튼**이 필요합니다 (실패한 단계부터 이어서 진행됩니다).

### 2-2. 요청

| ❓ | 요청 | 필요한 날 | 없으면 |
| --- | --- | --- | --- |
| ❓ | 화면 목록·흐름, API 계약 초안 검토 | 10/5 | 초안대로 진행 |
| ❓ | **Vercel 배포 주소** (CORS 허용 목록에 넣어야 화면에서 API 호출 가능) | 10/6 | 로컬(`localhost:3000`)만 허용 |
| ❓ | 진행 화면 단계 이름·순서 (지금 임시: 업로드 → 수치 재는 중 → 곡을 듣는 중 → 해석 쓰는 중) | 10/6 | 임시 문구 사용 |
| ❓ | 숏폼 템플릿 스펙 2~3종 (글자 위치·색·글꼴·움직임) | 10/7 | 기본 템플릿 1종 |
| ❓ | 채널 이미지 레이아웃, 제목 오버레이 스타일, 한글 글꼴 | 10/8 | Noto Sans KR |
| ❓ | 에러·대기 문구 말투 | 10/9 | 기본 문구 |

## 3. 팀원4님께 (샘플 곡 · 테스트 · 동의)

### 3-1. 전달

- 샘플 곡은 **WAV도 그대로 주셔도 됩니다** (200MB·10분 이하).
- 테스트 밴드 곡이 화면보다 먼저 오면, 백엔드가 **CLI로 대신 돌려서 결과를 전달**할 수 있습니다 (10/8 1차 피드백 B안).
- Gemini 무료 버전은 **호출 한도가 낮고 가끔 붐빕니다**(오늘도 1번 실패 후 재시도로 성공). 테스트 밴드 일정은 **한 시간에 몰리지 않게 나눠** 주세요.
- 자동으로 기록 중인 지표: 단계별 처리 시간, 실패와 원인. (노트 수정 횟수·재생성 횟수·다운로드 여부는 10/10에 추가)

### 3-2. 요청

| ❓ | 요청 | 필요한 날 | 없으면 |
| --- | --- | --- | --- |
| ❓ | **샘플 곡 3곡 이상** — 장르 다양하게, **한국어 보컬 곡 포함**. 곡마다 제목·아티스트·장르·한두 줄 소개, **가사가 있으면 텍스트 파일**도 | 10/5 | 무료 음원으로 시작 |
| ❓ | 짧은 곡(1분대)·긴 곡(6분 이상)·보컬 없는 곡 각 1개 (경계 상황 확인용) | 10/7 | |
| ❓ | **동의 문구** — 아래 4개 항목이 반드시 들어가야 합니다 | 10/7 | 백엔드 임시 문구 |
| ❓ | 결과보고서에 쓸 지표 목록 확정 | 10/7 | 기획 문서의 지표 목록 사용 |
| ❓ | 테스트 일정·팀 수 | 10/10 | |

**동의 문구 필수 항목** (동의 안 하면 처리하지 않습니다)
1. 자작곡(또는 권리 보유) 확약 — 필수
2. 개인정보 수집, **7일 보관 후 자동 삭제** — 필수
3. **음원이 Google Gemini API로 전송되고, 무료 버전은 입력이 Google 서비스 개선(학습)에 쓰일 수 있음** — 필수
4. 테스트 결과·곡을 발표 자료에 사용 — 선택
- 동의 문구에 버전 이름(예: `v1-1007`)을 붙여 주세요. 누가 어느 문구에 동의했는지 함께 저장합니다.
